# Supabase — этап 1, подготовка

Эта папка не подключена к приложению. Миграции не применялись к удалённой БД.
Frontend, гостевой режим и старое сохранение не изменены.

Основная документация: [архитектура и применение](../docs/SUPABASE_STAGE1.md).

Проверки без внешней базы:

```sh
python3 scripts/check_supabase_manifest.py
python3 scripts/test_supabase_local.py
```

Второй скрипт требует локальные `initdb`, `pg_ctl`, `psql`, создаёт новый кластер
в системной временной папке, слушает только закрытый Unix socket и останавливает
кластер в `finally`. Он не принимает URL подключения и не использует Supabase CLI.
Логи сохраняются в напечатанной временной папке.

`tests/bootstrap_local.sql` — только заглушки для такого кластера. Нельзя выполнять
их в Supabase. SQL-тесты не проверяют доставку писем, JWT через HTTP, работу файлового
backend Storage, подписанные URL или фактическую загрузку с телефона.
