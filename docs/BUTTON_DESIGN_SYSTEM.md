9 ноября 2026. Работа в `feature/ui-style-unification`, без commit, push и merge.

## Аудит и соответствие семейств

Существующие классы, `data-*`, обработчики, подписи и точки входа сохранены.
Один общий селектор для всех `button` не вводился. Основной блок системы —
`Premium controls` в конце `learning-polish.css`.

## Токены

Токены ссылаются на существующие переменные темы; новые значения не
подменяют палитру всего сайта.

| Токен | Значение |
| --- | --- |
| `--btn-primary-bg` | `--color-primary` / `#2b5d7e` |
| `--btn-primary-text` | `--color-on-primary` / `#fff9f1` |
| `--btn-primary-hover` | `--color-primary-hover` / `#234e6a` |
| `--btn-secondary-bg` | `--color-surface` / `#fff9f1` |
| `--btn-secondary-text` | `--color-primary-active` / `#1c4058` |
| `--btn-secondary-hover` | `--color-surface-alt` / `#f6f0e6` |
| `--btn-border` | `--color-border-strong` / `#938b7b` |
| `--btn-radius` | `16px` |
| `--btn-shadow` | `0 3px 0 var(--color-primary-active)` |
| `--btn-focus` | `--color-primary` |
| `--btn-accent-bg`, `--btn-accent-text`, `--btn-accent-hover` | mustard / основной текст / `#c7972f` |
| `--btn-success-bg`, `--btn-success-text` | светлая зелёная поверхность / тёмный зелёный текст |
| `--btn-danger-bg`, `--btn-danger-hover` | `#914343` / `#783636` |
| `--btn-height`, `--btn-compact-height` | `48px` / `44px` |
| `--btn-duration` | `160ms` |

Надписи: вес 650, line-height 1.4, межбуквенный интервал .005em,
базовый размер 14 px, компактный 13 px, расстояние до иконки 8 px.
Длинные переводы переносятся. Варианты ответа имеют высоту от 56 px.

Семейства меняют локальные `--control-*`. Небольшой общий блок отрисовки
с приоритетом перекрывает исторические `!important` в старых CSS-файлах;
сами цветовые семейства и их состояния не требуют `!important`.
Прежний дублирующий блок `One control vocabulary` удалён.

## Состояния и компоновка

- Hover меняет поверхность и границу; positioned audio не смещается.
- Active углубляет заливку и убирает нижнюю тень Primary.
- Focus-visible: контур 3 px с отступом 3 px, горчичный внутри синего hero.
- Disabled: читаемое приглушение, недоступный курсор, без тени.
- Busy: надпись и размеры сохраняются, появляется статичная нижняя линия;
  вращения и постоянной анимации нет. Capture-защита в `atelier.js` исключает
  повторный click по `aria-busy=true`, включая клавиатурную активацию.
  Существующие блокировки авторизации, квизов и PWA остаются на месте.
- `prefers-reduced-motion`: переходы отключены. Фон модальных окон и PWA
  затемняется без размытия и стеклянных эффектов.
- Действия книг прижаты к низу равных карточек. Уроки сохраняют парные ячейки
  статуса/действия. Кнопки слов переносятся в пределах карточки.
- Примеры слова теперь образуют адаптивную сетку и переносят длинные фразы:
  кнопка аудио остаётся доступной без прокрутки внутри длинного примера.
- Очистка поиска сохраняет вертикальное центрирование при hover/active;
  поле резервирует место под кнопку 44 px.

## Проверки

Браузерный тест: `tests/premium-buttons-browser.cjs`, отдельный Chrome,
локальный HTTP-сервер, без реальных записей в аккаунт.

Матрица: 18 экранов × 5 ширин (1440, 1024, 768, 390, 320) × 4 языка
(RU, UK, EN, SV) = 360 сочетаний. Проверяются выход элементов за экран,
переполнение надписей, высота целей, ширина иконных целей, отсутствие
градиентов у проверяемых кнопок и единственная видимая кнопка установки.

Функциональные сценарии и состояния:

- Hero → урок → список → урок → тест, ответы и завершение.
- Письменный ответ через настоящий submit формы.
- Избранное, «Знаю», следующий/предыдущий flashcard, flip.
- Вызов обработчика аудио и запуск теста видео, внешняя ссылка видео.
- Календарь: предыдущий месяц и возврат к текущему.
- Mobile drawer, sidebar destination, bottom menu, close, вкладки SFI.
- Login/register: открытие, switch, busy, защита от повторной отправки,
  восстановление после ошибки, закрытие; транспорт входа замокан.
- PWA: инструкция, закрытие, контракт native prompt с тестовым событием,
  защита от повторного prompt.
- Keyboard focus, desktop hover/active, стабильная ширина busy,
  capture-защита и reduced motion.
- Отображение существующего подтверждения удаления с тестовой identity;
  submit удаления не вызывается.

Машинные результаты: [verification.json](../reports/buttons/verification.json),
[layout-audit.json](../reports/buttons/layout-audit.json).

Дополнительно прошли существующие проверки `pwa-install`, `custom-controls`,
`cheats-layout`, `quiz-session`, `quiz-localization`, `quiz-rewards`,
`activity-calendar`, `service-worker`, `quality`, `ui_smoke`.
`word-progress-dom` без `SL_UX_DOM_MODULE` пропускает DOM-сценарии;
его пропуски не считаются успешной проверкой облачной интеграции.

## Оставшиеся вопросы и пределы проверки

Незакрытых проблем компоновки кнопок в проверенной матрице нет.
Существующая локализация некоторых названий режимов выводит ключи
`fillBlank`, `weekdays`, `months`, `dialogues`, `readText` в RU; содержимое
переводов в рамках этой задачи не изменялось. На очень узком экране название
бренда в шапке сокращается существующим ellipsis, логотип остаётся виден.

Live Supabase login/signup, синхронизация нескольких устройств и удаление
аккаунта не выполнялись. Аудио проверено до вызова обработчика, качество
шведского голоса зависит от устройства. Реальная установка в ОС не
выполнялась: проверены инструкция и lifecycle события. Браузерная проверка
выполнена в Chrome; Safari/iOS и физические сенсорные устройства требуют
отдельной ручной приёмки.
