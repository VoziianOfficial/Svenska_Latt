## Карта правил и языковая сверка

| ID | Содержание и существенное ограничение |
|---|---|
| `subjects` | jag, du, han, hon, hen, den, det, vi, ni, de; роль подлежащего не всегда означает деятеля, например в пассиве |
| `objects` | mig, dig, honom, henne, hen, den, det, oss, er, dem; после предлога объектная форма; помогает шведская роль, а не механический перенос русского/украинского падежа |
| `hen` | одна рекомендуемая форма для субъекта и объекта, hens для принадлежности; выбор местоимения не выводится из имени/профессии |
| `possessives` | владелец отдельно от рода/числа вещи; min bok без en и без определённого суффикса; принадлежность включает отношения, а не только владение |
| `min` | min/mitt/mina согласуется с шведским существительным, не полом владельца и не родом перевода |
| `din` | din/ditt/dina для одного адресата; dina означает много вещей, а не много владельцев |
| `shared` | неизменные hans/hennes/hens/deras; vår/vårt/våra и er/ert/era; две роли er |
| `den` | известный en-предмет → den, ett → det; plural → de/dem; отличаем артикль в den lilla lampan |
| `det` | Det är en stol представляет предмет; Det är min granne представляет человека; det regnar и det finns не требуют ett-антецедента |
| `de-dem` | субъектное de и объектное dem в стандартном письме; частое dom в речи; de как артикль — отдельная функция |
| `sin` | sin/sitt/sina для собственного предмета подлежащего третьего лица в изучаемом простом контексте; jag/du/vi/ni сохраняют min/din/vår/er |
| `clause` | в Eva säger att Leo tar sin cykel локальное подлежащее Leo; для велосипеда Евы — hennes; сложные инфинитивные/перспективные связи исключены из зачёта |
| `order` | V2 считает члены предложения, а не отдельные слова; du в Känner du honom? остаётся подлежащим после глагола |
| `extras` | обобщённое man; sig как возвратный объект; själv/själva как усиление или самостоятельность, без утверждения, что любой глагол требует sig |

Переводы RU/UK/EN/SV и все шведские примеры просмотрены автором. Уточнён контекст диалога соседей: присутствуют Alex и Kim, поэтому ni/er действительно обозначают обоих. Шведский род не переносится из перевода (`ett rum`, `ett kök`, `en lampa`). В чтении местоимения выделяются целыми словами, а не совпадающими подстроками; для sin/sitt и двух разных dem указаны конкретные связи.

Вопросы, требующие независимой языковой рецензии: естественность всех четырёх диалогов, педагогическая нагрузка расширения B, точность нюансов RU/UK/EN, полнота оговорок `sin`/`clause`, качество речи конкретных голосов устройств. До такой рецензии материал не обозначается как независимо сертифицированный.

## Проверка итоговых вариантов

[Матрица всех 24 вопросов и 96 вариантов](../reports/pronouns/option-audit.json) фиксирует правильный ответ, ограничение контекста и объяснение каждого варианта. Это авторская сверка, не отдельный эксперт.

- Контексты задают владельца, число вещей и адресатов. Нет угадывания han/hon/hen по имени или профессии.
- №3 спрашивает именно рекомендуемую Isof объектную форму; henom не объявляется несуществующей или безусловно неграмматичной.
- №9 отличает владельца Frida от подлежащего det; род piano не меняет hennes.
- №14 явно представляет человека в ответ на Vem är det?, а не заменяет известное en-слово.
- №15–18 задают своего/другого владельца и локальное подлежащее; спорные инфинитивные случаи не используются.
- №19 содержит грамматически правильный ответ с обратными ролями, который не соответствует требуемому смыслу.
- №21 спрашивает отсылку sin, а не делает вывод о фактическом владении квартирой.
- №23 различает несколько возможных множественных антецедентов по смыслу: «на шведском» относятся к газетам.
- Случаи de/dem som и неоднозначное без контекста barn исключены из однозначного зачёта. Финальные ситуации и текст не копируют готовые учебные предложения.

Автотест проходит каждую ветвь вариантов во всех четырёх локалях; меняет язык, проверяет стабильность canonical option ID и ссылки на правила. Это не доказывает лингвистическую однозначность без чтения условий человеком.
