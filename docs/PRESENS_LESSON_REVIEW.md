# Обзор переработки lesson-4: Presens

23 ноября 2026, Europe/Stockholm. Изменения локальные. **Клиентская глава и миграция 022 подготовлены и проверены локально на основании фактического baseline установленной 021.** Commit, push, merge, deploy и production SQL не выполнялись.

## Состав главы

| Материал | Реализовано |
|---|---|
| Грамматические блоки | 19, в пяти разделах |
| Таблицы | 10, с прокруткой на телефоне |
| Диалоги | 4 × 8 реплик, переводы RU/UK/EN и исходный SV |
| Мини-текст | 12 связанных предложений о Самире в Вестеросе |
| Тренировка | 40 заданий: исходные 20 + 20 новых |
| Из них понимание диалогов | 8, по два на диалог |
| Из них понимание рассказа | 4 |
| Письменная практика | 5 заданий: 2 прежние разминки + 3 новых самостоятельных текста |
| Продолжения разговоров | 4 задания по четыре реплики, без автоматической оценки |
| Итоговый тест | 24 новых вопроса, отдельный банк `presens-final-v1` |
| Локализации | RU / UK / EN / SV |

Материал находится **в существующем `lesson-4.learningV2`**, ID модуля `presens-a-v2` сохранён, revision повышен до 2. Второй системы уроков нет. Исходные 20 объектов тренировочных вопросов побайтно эквивалентны исходному JSON после нормализации сериализации; их ID, ответы, варианты и объяснения сохранены. Сохранены оба прежних ID письменных разминок, их условия и образцы; добавлены заголовки и подсказки самопроверки.

Теория охватывает действие сейчас, привычки, факты/состояния, будущее с ясным временем; инфинитив/основу/личную форму; одинаковую форму для всех лиц; четыре группы; особые формы; veta; kan/vill; ska/måste; inte; V2; два типа вопросов; время и частоту; итоговую самопроверку ошибок.

Сравнения специально ограничивают обобщения: `-er` не доказывает группу 2, короткая форма с `-r` не доказывает группу 3, `vet/kan/vill/ska/måste` не получают универсальное `r`, `är` не добавляется перед каждым действием. `Måste` показан без выдуманного общеупотребительного инфинитива. `Skola` объяснён как словарный инфинитив для `ska`. Прошедшие времена не тренируются. В диалогах используются простые прямые вопросы.

Обстоятельства времени (`nu`, `idag`, `varje dag`, `på morgonen`, `på kvällen`) и частота (`ofta`, `ibland`, `alltid`, `aldrig`) разведены по двум таблицам. V2 описывает вторую **часть предложения**, а не второе слово. Для отрицания приведены как прямой порядок, так и начало со времени и модальный глагол.

## Источники и пределы проверки

Сверка выполнена по открытым первичным источникам. Тексты, ситуации и упражнения оригинальные; фрагменты учебников не копировались.

- [Skolverket: актуальная страница курс-плана SFI](https://www.skolverket.se/undervisning/komvux/komvux-i-svenska-for-invandrare-sfi/kursplan-for-svenska-for-invandrare-2017/subjects/SFI?schoolType=VUXSFI&timespan=LATEST) и [комментарий к курс-плану](https://www.skolverket.se/download/18.3770ea921807432e6c73e4d/1660633264584/pdf10226.pdf): повседневные ситуации, поддержка учащегося A, простые разговоры и тексты B. Развёрнутые письменные задания используют модели и самопроверку; глава не удостоверяет прохождение всего курса SFI.
- [Svenska Akademiens grammatik, том 2](https://svenska.se/SAG_Volym_2.pdf), глава Verb, в частности разделы о спряжении и дефектных/неправильных вспомогательных глаголах: основа первой группы с `a`, различия групп, `veta/kunna/vilja`, `vara/ha`, `skola/måste`.
- [Svenska Akademiens grammatik, том 4](https://svenska.se/SAG_Volym_4.pdf): главы о структуре предложения, satsadverbial, времени, модальных глаголах и главных предложениях.
- [Svenska Akademien: presens](https://svenska.se/?activeTab=alla&exactMatch=true&homografNr=1&id=9487237&q=presens), [gå](https://www.svenska.se/?activeTab=so&exactMatch=true&q=g%C3%A5): словарные определения и формы. Страницы поиска SAOL динамические; их пустая оболочка не считается самостоятельным подтверждением всех форм. Для сверки форм использован также открытый SAG.
- [Isof: idag или i dag](https://frageladan.isof.se/faqs/23289): допустимые варианты написания временных выражений. Прежний source ID `isof-time` сохранён, ссылка и название уточнены под реально проверенный материал.
- [Natur & Kultur: Mål 1](https://www.nok.se/titlar/laromedel-b2/mal-mal-1/fe87c80a-0c2c-4820-808d-15235e146c6d) и [Målgrammatiken](https://www.nok.se/titlar/laromedel-b2/malgrammatiken/f37fd212-8f42-41f6-8251-fda43dc0b8c9): проверены открытые страницы издателя. Полный текст этих учебников не был предоставлен и не использовался; постраничная сверка с ними не заявляется.

**Независимая языковая рецензия специалистом не проведена.** Редакторская сверка агентом и автоматические проверки не являются такой рецензией. Отдельная акустическая оценка произношения также не проводилась.

## Интерфейс и аудио

Используется существующий компонент `pronouns-lesson.js`, выделенный в общую фабрику глав с двумя экземплярами для уроков 3 и 4. Стили, таблицы, задания, TTS, переходы к правилам и письменная самопроверка переиспользованы. Обработчики ограничены текущей главой; черновики разделены по уроку и владельцу аккаунта. HTML-символы в ответах экранируются. Данные `learningV2` при отображении не мутируются.

Все шведские примеры имеют прослушивание; доступны отдельные реплики и предложения, диалоги и рассказ целиком, обычный и медленный темп, остановка и сообщение об отсутствии sv-SE. Это синтез речи устройства. Свободные письменные ответы и продолжения диалогов не получают формальной оценки грамматики или XP. Черновики живут в памяти вкладки до перезагрузки — это явно написано в интерфейсе.

Глобальные Hero, favicon, авторизация и содержимое других уроков не менялись. В `index.html` изменён только cache-busting параметр общего JS-компонента. PWA-логика не менялась; для согласованного выпуска 022 обновлён только идентификатор кэша. Клиент и SQL используют одну версию `static-18bd9e23b62c3382`.
