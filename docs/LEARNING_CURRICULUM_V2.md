## Действующая и будущая структура

Действующая программа [Skolverket 2017](https://www.skolverket.se/undervisning/komvux/komvux-i-svenska-for-invandrare-sfi/kursplan-for-svenska-for-invandrare-2017/subjects/SFI?schoolType=VUXSFI&timespan=LATEST) различает пять областей: понимание на слух, чтение, устное взаимодействие, устная продукция и письмо. ## Принцип последовательности

Каждая ячейка «уроки» содержит **четыре последовательных занятия**, не один большой урок. Чередование: понятная ситуация → правило с опорами → новая ситуация → самостоятельный результат. В каждом занятии нужны минимум 20 оригинальных закрытых/ограниченно открытых заданий и отдельное письмо с рубрикой. Часть заданий проверяет чтение и слушание; одинаковый вопрос на перевод не считается новым способом применения правила. Шаг к следующей теме основывается на конкретном навыке; старое достижение не отменяется из-за редакции курса.

Для аудирования сначала использовать оригинальную озвучку с проверенным текстом и отдельными заданиями без показа транскрипта до ответа. Текущий браузерный TTS и кнопка «прослушать» не доказывают наличие полноценной слуховой проверки. Для говорения — речевая задача, образец и критерии понятности; без оценивания распознавания речи нельзя выдавать автоматическую отметку о качестве произношения.

## A — конкретные потребности с поддержкой

Результат: понимает простую информацию о знакомой ситуации, обменивается простыми репликами с поддержкой, сообщает личные сведения, заполняет короткую запись по образцу. Короткое сообщение в приложении — учебное упражнение; действующий критерий письма A прежде всего касается личных сведений и переноса важной информации, а не самостоятельного эссе.

## Очередь реализации и критерий готовности

1. Завершён текущий технический пилот presens; провести независимую SV/RU/UK/EN редактуру и наблюдение за одним учащимся A.
2. Переработать A2 (знакомство, субъектные формы, вопросы, анкета), затем A1/A3–A6; не сдвигать ID старых уроков.
3. Расширить B бытовыми рассказами и письмом, затем C связностью и порядком слов, затем D источниками и аргументацией. Для каждого следующего блока — отдельное небольшое изменение и отчёт.
4. Подготовить отдельно рецензируемый план обновления доверенного банка тестов: новые постоянные ID вопросов, поддержка старых сессий и старых наград, синхронный выпуск клиента/сервера. Применение SQL требует отдельного решения.
5. Выпуск урока: все четыре языка, 20+ проверяемых заданий, письмо и рубрика, источники на уровне правил, автоматические проверки и независимая содержательная редактура. Структурный PASS не заменяет языковой review.
