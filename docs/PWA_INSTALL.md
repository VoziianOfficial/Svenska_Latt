## Что проверить вручную

1. После отдельной публикации открыть сайт в Chrome/Edge, нажать установку, принять системное приглашение и запустить приложение из меню ОС. В standalone кнопки установки быть не должно. Проверить также отмену приглашения.
2. На iPhone/iPad проверить Safari → «Поделиться» → «На экран Домой», запуск и иконку. На Android проверить как нативное приглашение, так и инструкции меню браузера; на Mac — Safari → «Добавить в Dock».
3. В установленном приложении открыть урок, карточки, тест и видео; переключить язык; после онлайн-запуска отключить сеть и проверить локальные учебные разделы. Внешние видео не становятся офлайн-ресурсами.
4. Проверить результат на опубликованном HTTPS-адресе GitHub Pages: локальные проверки не заменяют проверку сервера публикации и ОС.

## Проверка обновления иконки существующей установки

1. Сохранить прежнюю установку и опубликовать файлы вместе: index, CSS, app.js, pwa-install.js, manifest, sw.js и обе v2-иконки (или полную runtime-сборку).
2. Открыть `/Svenska_Latt/` онлайн. В DevTools → Application проверить активный новый SW, URL `icon-192-v2.png` и `icon-512-v2.png` в Manifest и загрузку PNG без ошибок. В сборке RELEASE — вычисленный хеш, при публикации исходников — `2026-11-08-lesson-covers-001`.
3. Закрыть окна установленного приложения, открыть его снова и проверить значок в меню ОС/на домашнем экране. Если браузер предлагает подтвердить обновление приложения, принять предложение.
4. Новый URL иконки подготовлен, но срок и применение обновления определяют браузер и ОС. На отдельных платформах старая иконка может сохраняться. Не удалять установку и её локальные данные ради этого теста; новую установку можно проверить отдельно на тестовом устройстве.
5. v2-файлы идентичны текущим премиальным исходникам. Если в установленном приложении уже была эта картинка, визуального отличия не будет: проверить новые URL в манифесте.

Документация: [нативное приглашение](https://web.dev/articles/customize-install), [обновления установленных приложений в Chrome](https://developer.chrome.com/blog/improvements-to-web-app-updates), [Safari на iPhone](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios), [Safari на Mac](https://support.apple.com/104996).
