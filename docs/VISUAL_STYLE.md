# Svenska Lätt: единый визуальный стиль

Изменения от 9 ноября 2026 года. Направление: тёплая скандинавская книга,
спокойные поверхности, ясные действия и небольшие игровые акценты.

## Цветовая система

Авторитетный блок `Swedish storybook theme` находится в конце
`learning-polish.css`, после существующих стилей.

| CSS-переменная | Цвет | Назначение |
| --- | --- | --- |
| `--color-primary` | `#2B5D7E` | Swedish Blue: основные действия, ссылки, выбранная навигация, прогресс |
| `--color-secondary` | `#D6A43A` | Warm Mustard: главное действие в hero, небольшие тёплые акценты |
| `--color-accent` | `#B85C5C` | Berry: ягодные акценты, основа палитры ошибок и уровня D |
| `--color-surface` | `#FFF9F1` | Warm Ivory: карточки, шапка, сайдбар, поля, диалоги |
| `--color-surface-alt` | `#F6F0E6` | Cream: вложенные блоки, примеры, спокойные вторичные поверхности |
| `--color-bg` | `#F3EEE5` | Тёплый бежевый фон приложения |
| `--color-text` | `#24313A` | Основной текст и заголовки |
| `--color-text-soft` | `#59656B` | Подписи и вторичный текст |
| `--color-border` | `#DCD4C6` | Деликатные разделители и границы карточек |
| `--color-success` | `#6E8B6B` | Soft Green: успешные состояния и активность |
| `--color-warning` | `#D6A43A` | Предупреждения и тёплые акценты |
| `--color-peach` | `#E6B9A1` | Дополнительный Dusty Peach для дальнейшего развития палитры |

Для синего, зелёного, ягодного и горчичного цветов предусмотрены отдельные
светлые поверхности и тёмные цвета текста. Светлый зелёный или горчичный
не используются как цвет мелкого текста на кремовом фоне.
Поля имеют более контрастную границу `--color-border-strong: #938B7B`.

Расчёт контраста основных сочетаний:

| Сочетание | Контраст |
| --- | --- |
| Основной текст / ivory | 12,74:1 |
| Вторичный текст / ivory | 5,74:1 |
| Вторичный текст / фон приложения | 5,19:1 |
| Ivory / основной синий | 6,76:1 |
| Основной текст / mustard | 5,86:1 |
| Тёмный зелёный / светлая зелёная поверхность | 6,14:1 |
| Тёмный ягодный / светлая ягодная поверхность | 5,59:1 |

Это расчёт заданных цветов, а не полная сертификация доступности интерфейса.

## Логика компонентов

- Основные поверхности однотонные; убраны декоративные переливы и тяжёлые тени.
  Затемнение поверх фотографии лицевой стороны флеш-карточки сохраняется
  для читаемости текста.
- Hero получил плоский синий фон и арочное обрамление существующей фотографии
  Стокгольма. На узком экране фотография скрывается, текст занимает всю ширину.
  Новые изображения и персонажи не добавлялись.
- Карточки используют радиус 20 px, крупные панели — 24 px, элементы управления —
  12 px. Основные интервалы: 4, 8, 12, 16, 24 и 32 px.
- Карточки одной группы получили общие отступы, поверхности и правила высоты.
  Карточки действий используют мягкий синий, темы — мягкий зелёный; уровни A–D
  различаются зелёным, синим, горчичным и ягодным акцентами.
- Словарь больше не меняет фон каждой следующей карточки по случайной радуге.
  Примеры, формы слов, времена, чтение и шпаргалки используют общие поверхности.
- Статистика собирается в равные колонки: четыре на широком экране, две при
  ширине до 1200 px. Существующие карусели и их обработчики сохранены.
- Основная кнопка синяя, вторичная имеет мягкую синюю поверхность,
  спокойная дополнительная — ivory с границей. Горчичная кнопка выделяет
  основное действие в hero. Hover меняет поверхность и границу без скачка позиции;
  active использует более глубокий синий. Поддерживается reduced motion.
- Убраны завершающие декоративные стрелки из 35 шаблонов подписей кнопок
  и декоративная стрелка открытия урока. Навигационные стрелки каруселей,
  календаря, возврата и раскрытия списков сохранены.
- Focus использует отчётливое синее кольцо; внутри синего hero — горчичное.
  Поиск выделяет общую рамку при фокусе вложенного поля.
- Прогресс использует синий, «изучено» и успех — зелёный, «избранное» —
  горчичный, ошибки — ягодный. Выбранные состояния имеют тёмный читаемый текст.
- Профиль, статистика времени, выпадающие списки, уведомления, диалоги и footer
  приведены к тем же цветам, границам и теням.

## Проверка

- Все четыре CSS-файла проходят разбор PostCSS; JavaScript проходит `node --check`.
- Все 11 обязательных цветовых токенов присутствуют; ссылки между 83
  определениями переменных темы разрешаются без циклов.
- Изменение `app.js` сверено с Git: оно в точности равно удалению
  ` →` перед закрывающим тегом кнопки, без других изменений.
- Существующие проверки: `quality.cjs` (4 языка, 50 уроков, 1006 слов,
  14 режимов квизов), `cheats-layout.cjs`, `lesson-covers.cjs`,
  `custom-controls.cjs`, `quiz-session.cjs`, `activity-calendar.cjs`,
  `study-time.cjs`, `manual-reviews.cjs`, `pwa-install.cjs` и
  `service-worker.cjs` прошли.
- `word-buttons-integration.cjs` и `word-progress-dom.cjs` пропускают DOM-проверки без
  `SL_UX_DOM_MODULE`; этот запуск не считается подтверждением интеграции.
- Главная страница просмотрена в локальном Chrome при ширине 1172 px.
  Проверка полного набора экранов на desktop, tablet и mobile ограничена
  тайм-аутами и нестабильным управлением браузером. Правила адаптивности
  проверены по исходникам; полный визуальный прогон остаётся необходимым.
