## Смысловая проверка

Просмотрены все 1006 карточек на 21 контактном листе и отдельном листе новых
фото. В галерее [ручного просмотра](photo-review.html) — 699 карточек.
У каждой есть слово, перевод, ID, изображение, причина сомнения и ссылка
на атрибуцию. Машиночитаемый результат: photo-semantic-review.json.

Отметка означает сомнение, а не автоматически установленную ошибку. Список
консервативный: включает рисунки/документы, ложные совпадения названий,
неясные предметы, действия и отношения, косвенные сцены, неоднозначные
абстрактные слова. Для оставшихся карточек явной проблемы на миниатюре не
замечено; это не гарантирует точность мелких деталей. Восемь новых контекстных
изображений также отмечены. Например, редкое затмение иллюстрирует sällan,
а совместный быт пары не доказывает её брачный статус для sambo.
Замены старых изображений не выполнялись.

## Лицензии: работа выполнена, вопросы для запуска остаются

Создана [публичная страница атрибуции](../photo-credits.html), доступная из
существующего футера. Дизайн и учебная логика приложения сохранены.
Страница содержит 1006 записей, поиск, локальные миниатюры, авторов при наличии,
названия работ, ссылки на источники и точные версии/юрисдикции лицензий,
сведения об обработке и уведомления источников. HTML из метаданных не
исполняется: сведения выводятся экранированным текстом.

Проверены запросами Commons все 856 скачанных записей (841 прежняя + 15 новых).
Для 855 получены актуальные метаданные. Снимки ответов сохранены в
commons-evidence/. Отличий заявленных лицензий от исходного реестра у
доступных файлов не обнаружено; это проверка данных источника, а не
независимое подтверждение всей цепочки авторских прав.

Из 18 прежних CC-записей без автора восстановлены пять по прямым указаниям:
Jake N., Stany Dederen, Rama, Mikko Hongisto и Derek Jensen (Tysto).
Дополнительно восстановлен ocrho для Public domain фотографии DVD.
Имена не определялись по изображённому человеку, загрузившему файл аккаунту
или названию учреждения без прямого указания в источнике.

Нерешённые вопросы:

- У 13 CC-файлов достоверный автор не установлен: w-ledsen, w-arg, w-lugn,
  w-hand, w-arm, w-mage, lex-0043, lex-0058, lex-0060, lex-0074, lex-0239,
  lex-0351, lex-0387. Сохранены сведения об источниках, в том числе
  Wellcome Images / Barts Health NHS Trust Archive, без подмены автора.
- Ещё у пяти Public domain / CC0 записей автор не установлен: w-varm,
  lex-0091, lex-0195, lex-0197, extra-24. Они явно обозначены как неизвестные.
- У w-ute Commons вернул missing для сохранённого pageid 201612430.
  Повторный запрос по названию получил HTTP 403, поэтому причина недоступности
  не установлена. Прежняя лицензия и автор показаны как исторические сведения;
  текущая лицензия не переподтверждена. Фото сохранено согласно указанию.
- 150 прежних привязок относятся к историческому набору AI-генерации.
  Они сохранены и отмечены отдельно; им не приписаны фотографы и CC-лицензии.
  У девяти из них исторический статус generated, а не reviewed; предыдущая
  привязка сохранена, визуальный просмотр выполнен на этом этапе.

CC BY требует атрибуции и соблюдения своей версии лицензии; для адаптаций
CC BY-SA сохранена та же лицензия. Уведомления о преобразовании новых файлов
точные; для старых явно указано, что подробная история не зафиксирована.
Условия относятся к изображениям и не изменяют лицензию приложения.
Официальные условия: [CC BY](https://creativecommons.org/licenses/by/4.0/),
[CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/),
[CC0](https://creativecommons.org/publicdomain/zero/1.0/).

## Проверки и сборка

Прошли шесть существующих JS-проверок: photo-links, flashcard-media, quality,
service-worker, word-icons и ui_smoke. Пройдены все пять Python-тестов сервера,
включая новую страницу и новый JSON источников. UI smoke выполняется в VM;
его диагностические сообщения о кириллице в служебных атрибутах/названиях
языков не являются проверкой внешнего вида в браузере.

Отдельно проверены синтаксис Python/JS, все локальные ссылки страницы
атрибуции и галереи, 1006 ответов HTTP 200 с image/webp из собранного deploy,
1006 записей атрибуции и хеши всех 1418 файлов сборки. Публичная страница
статическая и не требует Supabase, CDN или сторонних библиотек.

Браузерная проверка не выполнена: Browser runtime сообщил No browser is
available и вернул пустой список браузеров. Поэтому нельзя утверждать,
что все виды проверки интерфейса выполнены. Внешний вид новых квадратных
фотографий проверен по локальному контактному листу.

Папка deploy пересобрана: release f4199a8d182bcd2a, 1418 файлов,
78 618 001 байт. Предыдущая папка сохранена во временной резервной копии;
путь находится в photo-release-validation.json. Контактные листы, частная
галерея, сырые метаданные аудита и инструменты проверки в deploy не включены.

Supabase не подключался. Внешний деплой, commit и push не выполнялись.

Воспроизведение: scripts/build_photo_audit.py (Pillow), стандартные тесты,
scripts/build_deploy.py <новая-папка>, scripts/verify_photo_release.py <папка>.
Последний скрипт запускает только локальный сервер с временной тестовой БД.
