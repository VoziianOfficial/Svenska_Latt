# Предложение страницы атрибуции — без изменения интерфейса

Проверен исходный `assets/flashcards/photo-credits-imported.json`; файл оставлен
побайтно неизменным и включён в `deploy/`. Полный список файлов, слов, авторов,
источников и лицензий с флагами проверки: `photo-license-audit.json`.

Из 841 импортированной фотографии:

- 570 имеют CC BY / CC BY-SA и требуют публичной атрибуции.
- 442 из этих 570 имеют CC BY-SA; для адаптаций нужно соблюдать ShareAlike.
- 80 имеют CC0, 191 помечены Public domain. Обязательная атрибуция по CC0
  отсутствует; сохранение источника и автора всё равно полезно. Public domain
  здесь — сведения импортного реестра, а не независимое подтверждение статуса.
- У 18 записей CC BY / CC BY-SA пустое поле `author`. Точный список ID находится
  в `incomplete_required_records` полного отчёта. Ссылки на источники сохранены;
  авторов нужно восстановить по карточкам Commons перед публикацией.

После согласования предлагается отдельная `photo-credits.html` со ссылкой
«Фото и лицензии» в существующем футере. Страница может строиться статически
из JSON, без Supabase и сторонних библиотек. Для каждой фотографии:
миниатюра существующего файла, шведское слово, название исходной работы,
автор / требуемая строка атрибуции, ссылка на страницу источника, точное название
и ссылка на версию лицензии, сведения об изменениях исходной работы.
Сохранить предоставленные copyright notices и прежние сведения об изменениях.
Имена авторов выводить как текст, не вставлять поля JSON как HTML.

Предлагаемый текст об обработке: «Локальная копия в WebP; размеры и кадрирование
нужно подтвердить по истории импорта». В этой подготовке изображения вообще
не преобразовывались. Скрипт импорта предусматривает преобразование / обрезку,
но точную историю каждой конкретной фотографии нельзя вывести из одного JSON.
Не заявлять «оригинал без изменений» относительно фотографии на Commons.
При распространении адаптированной фотографии CC BY-SA сохранять применимую
совместимую лицензию; это не основание менять лицензию всего приложения.

Остальные 150 отображаемых привязок не имеют записи в импортном JSON.
137 отмечены reviewed в историческом generation-status.json; 9 числительных
ещё помечены generated (en, tre, fyra, fem, sex, sju, åtta, nio, tio);
4 привязки используют общий work.webp. Они сохранены как есть. Происхождение
неиспользуемых локальных файлов и аватара также нужно сверить перед публикацией.
README с описанием AI-генерации не следует распространять на импортированные фото.

Источники требований, проверенные 16 октября 2026:

- CC BY: https://creativecommons.org/licenses/by/4.0/
- CC BY-SA: https://creativecommons.org/licenses/by-sa/4.0/
- CC0: https://creativecommons.org/publicdomain/zero/1.0/

Для каждой записи использовать именно её версию / юрисдикцию лицензии из JSON,
а не автоматически заменять лицензии 2.0, 2.5 и 3.0 на 4.0.
Страница и ссылка пока не созданы: это предложение для согласования.
