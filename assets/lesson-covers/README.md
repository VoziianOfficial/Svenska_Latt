# Обложки уроков A–D

50 отдельных изображений, сгенерированных встроенным `image_gen` для каждой темы.
Это новые фотографии, а не скачанные стоковые изображения и не готовые шаблоны.
В [prompts.json](prompts.json) сохранён точный набор запросов генерации: `common_prompt + scene`, либо `prompt_override`, если он указан.

## Формат и вес

Фактически: **50 фотографий, 2 265 872 байта (2,27 МБ / 2,16 МиБ)**; средний файл — около 45 КБ.

- Все финальные обложки: **768×512 px, WebP, 3:2** — ровно как область обложки карточки.
- Уменьшение Lanczos, качество 80 (при необходимости 78/76), без EXIF/ICC и других лишних метаданных.
- Лимит одного файла — 90 КиБ, всего набора — 3 МиБ; фактические размеры и SHA-256 записаны в `manifest.json`.
- Большие исходные PNG остаются вне репозитория. В runtime-сборку входят только WebP.
- Никакой обрезки фотографий: компонент сохраняет полный кадр через `object-fit: contain`.

## Связь с уроками

Файлы привязаны к постоянным ID уроков в `LESSON_COVERS` (`atelier.js`).
Номер урока внутри уровня не равен ID: например, «Школа и класс» — `lesson-35`.
Нельзя выбирать фотографию по позиции карточки, языку интерфейса или названию перевода.

## Загрузка и офлайн

Первая видимая обложка загружается сразу, остальные — лениво. Только один запрос на каждое изображение, без фонового дубликата.
Просмотренные обложки используют существующий ограниченный фотокэш Service Worker (общий лимит 150 с остальными фотографиями).
Все 50 изображений не добавляются в обязательный precache и не скачиваются при установке PWA.

## Повторная оптимизация исходников

Создать вне репозитория приватный JSON со списком путей к сгенерированным PNG:

```json
[{"id":"lesson-1","path":"/path/to/original.png"}]
```

В реальном списке должны быть все 50 ID без повторов. Затем:

```sh
python3 scripts/build_lesson_covers.py /path/to/private-sources.json
node tests/lesson-covers.cjs
node tests/service-worker.cjs
```

Скрипт требует Pillow с поддержкой WebP, не обращается к API и отказывается обрезать или увеличивать маленькие исходники.
При следующей замене изображений использовать новые имена `v2` и обновить mapping и релиз SW.

## Проверка

- Все 50 изображений загружаются и декодируются как 768×512 WebP.
- 80 сочетаний: 320/390/768/1024/1440 px × RU/UK/EN/SV × A/B/C/D — правильная привязка к темам, без переполнения и обрезки.
- Проверены ленивая загрузка и ровные ячейки кнопок.
- После офлайн-перезагрузки все 50 предварительно просмотренных обложек доступны из фотокэша; в shell-precache их нет.
- Runtime-сборка содержит все 50 WebP с совпадающими хешами и не содержит исходных PNG.
- Учебные данные, авторизация и прогресс не изменены.
