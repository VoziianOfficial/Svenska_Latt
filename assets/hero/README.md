# Karlskrona hero photographs

Five real photographs from Wikimedia Commons, selected for soft light, warm architecture and autumn colours. The original photographic scenes are unchanged. Display uses a warm, low-contrast CSS treatment and responsive cropping. Both 800/1600 px WebP versions retain the source licence.

- **Karlskrona main square Dec 2008.jpg** — Magnus Bäck; [Public domain](https://commons.wikimedia.org/wiki/Commons:Public_domain); [source](https://commons.wikimedia.org/wiki/File:Karlskrona_main_square_Dec_2008.jpg). Files: stortorget-evening-{800,1600}.webp.
- **Karlskrona.jpg** — guldfisken from Russia; [CC BY 2.0](https://creativecommons.org/licenses/by/2.0); [source](https://commons.wikimedia.org/wiki/File:Karlskrona.jpg). Files: marinmuseum-soft-{800,1600}.webp.
- **Karlskrona kamienica Stortorget 10 2.jpg** — Andrzej Otrębski; [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0); [source](https://commons.wikimedia.org/wiki/File:Karlskrona_kamienica_Stortorget_10_2.jpg). Files: stortorget-pastel-{800,1600}.webp.
- **Autumn in sweden.jpg** — Rajnandaphotography; [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0); [source](https://commons.wikimedia.org/wiki/File:Autumn_in_sweden.jpg). Files: karlskrona-autumn-{800,1600}.webp.
- **Drottningskärs kastell evening shore view.jpg** — Magnus Bäck; [Public domain](https://commons.wikimedia.org/wiki/Commons:Public_domain); [source](https://commons.wikimedia.org/wiki/File:Drottningsk%C3%A4rs_kastell_evening_shore_view.jpg). Files: drotningskar-golden-{800,1600}.webp.

Previous hero assets remain available for rollback; their source credits are preserved in credits-previous.json. The slideshow uses only the five photographs listed above.
