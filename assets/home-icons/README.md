# Home shortcut illustrations

Nine original images generated with the built-in ImageGen tool for the home shortcut cards. They share realistic paper, linen, wood and satin metal materials, a restrained sage/ochre/blue palette, and transparent backgrounds.

Final website assets are the nine sibling `*-v1.webp` files (256 × 256 pixels). The cards display them on the right at 36–62 CSS pixels. Images are decorative; the visible text names each destination.

[prompts.json](./prompts.json) records the full final prompt, original generated PNG path and project asset path for each image. Original generated PNGs remain in the generation directory; the website uses only the project-local WebP files. Conversion preserves the generated alpha channel.

The service worker precaches these small assets for offline navigation.
